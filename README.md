# Orbital fox

This is a sandbox game about a fox who has been swept far away into a strange star system made up of suspiciously small planets.  
The fox must explore these planets—traveling between orbits and gathering resources to repair its ship — while simultaneously deciphering an unfamiliar language.

# What will be implemented here

- Planetary cores
- Ability to travel between planets
- Ability to view planetary orbital data

# In the long term

- Creation and activation of planetary cores
- Full planetary destructibility
- Ability to shift orbits via towing and other technologies
- Blocks that allow changing planets
- Other features and interesting elements

# Player control

| Key | Action | 
| :---: | :---: |
| f | switch fly/walk mode |
| i | hide/show planet`s frames |
| p | start/stop planet spawn |
| left click | when cursor on a planet and frames are showed - more info<br>if planet spawn is online - spawn planet|
| w | walk mode - jump<br>fly mode - up |
| a | walk mode - go left<bt>fly mode - rotate left |
| s | walk mode - not used<bt>fly mode - down |
| d | walk mode - go right<bt>fly mode - rotate right |
